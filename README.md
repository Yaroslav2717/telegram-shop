# 🛍️ Премиальный сайт-каталог товаров с базой данных, админ-панелью и Telegram-ботом

Полнофункциональный современный сайт-каталог товаров, написанный на Node.js со встроенной базой данных SQLite (`node:sqlite`) без необходимости установки сторонних зависимостей (`node_modules` не требуются).

---

## 🌟 Реализованные функции

1. **Age-Gate (Проверка возраста 18+)**:
   - При первом входе на сайт появляется стильное модальное окно с вопросом: *"Вам есть 18 лет?"*
   - Кнопки: **"Да, мне есть 18 лет"** и **"Нет, мне меньше 18"**.
   - Допуск к сайту и товарам предоставляется **только при выборе "Да"**. Выбор сохраняется в `localStorage`.
   - При выборе "Нет" доступ к сайту блокируется с предупреждением об ограничении возраста.
   - В подвале сайта есть кнопка сброса статуса возраста для удобной проверки работы Age-Gate.

2. **Каталог товаров**:
   - Адаптивная сетка карточек товаров с фото, названием, категорией, кратким описанием и ценой в рублях.
   - Фильтрация по категориям в реальном времени.
   - Живой поиск по названию и описанию.
   - Модальное окно просмотра деталей товара с крупным изображением.
   - База данных предзаполнена стартовыми товарами при первом запуске.

3. **Корзина и оформление заказа**:
   - Выезжающая боковая шторка корзины со счетчиком и управлением количеством (+ / − / удалить).
   - Подсчет итоговой суммы в реальном времени.
   - Форма оформления заказа: Имя, Телефон/Telegram ник, Адрес доставки / пожелания.
   - Автоматическая отправка структурированного уведомления о заказе в **Telegram-бот**.
   - Экран подтверждения с присвоением индивидуального номера заказа (`#ID`).

4. **Административная панель (`/admin`)**:
   - Авторизация по паролю (пароль по умолчанию: `admin123`).
   - Сводный дашборд статистики: количество товаров, общее число заказов, сумма продаж, новые заказы.
   - **Управление товарами (CRUD)**:
     - Добавление новых позиций.
     - Редактирование существующих товаров.
     - Удаление товаров с подтверждением.
     - **Загрузка изображений**: Drag-and-Drop или выбор файла с вашего компьютера с автоматическим сохранением на сервер (`uploads/`) и моментальным предпросмотром, либо указание прямой ссылки.
     - Управление видимостью товара (активен / скрыт).
   - **Управление заказами**:
     - Просмотр всех заказов, данных покупателей, состава заказа и суммы.
     - Быстрая смена статусов: *«Новый»*, *«В обработке»*, *«Выполнен»*, *«Отменен»*.
   - **Интеграция с Telegram**:
     - Ввод токена бота (`Bot Token`) и `Chat ID`.
     - Кнопка «Отправить тестовое сообщение» для мгновенной проверки связи с Telegram.
     - Смена пароля администратора.

## 🚀 Как запустить проект

### Вариант 1 (Быстрый запуск на Windows):
Просто дважды кликните по файлу **`start.bat`** в папке проекта.

### Вариант 2 (Через терминал):
Откройте PowerShell или командную строку в папке проекта и выполните:
```bash
node server.js
```

Сервер запустится на порту `3000`:
- 🛒 **Витрина магазина:** [http://localhost:3000](http://localhost:3000)
- ⚙️ **Админ-панель:** [http://localhost:3000/admin](http://localhost:3000/admin)
- 🔑 **Пароль админа по умолчанию:** `admin123`

## 🤖 Как настроить Telegram-бота за 2 минуты

1. **Создайте бота в Telegram:**
   - Откройте бота [@BotFather](https://t.me/BotFather) в Telegram.
   - Отправьте команду `/newbot`, укажите имя и юзернейм вашего бота (например, `MyCatalogStore_bot`).
   - Скопируйте полученный **HTTP API токен** (вида `7123456789:AAH...`).

2. **Узнайте свой Chat ID:**
   - Напишите любое сообщение боту [@userinfobot](https://t.me/userinfobot).
   - Он пришлет ваш цифровой **Id** (например, `123456789`).

3. **Активируйте вашего бота:**
   - Перейдите в созданного вами бота и нажмите кнопку **«Запустить»** (`/start`). *Это обязательный шаг Telegram API.*

4. **Подключите бота в админ-панели:**
   - Перейдите в [http://localhost:3000/admin](http://localhost:3000/admin).
   - Перейдите во вкладку **«Telegram & Настройки»**.
   - Вставьте **Bot Token** и **Chat ID**.
   - Нажмите кнопку **«Отправить тестовое сообщение»** — вам в Telegram мгновенно придет тестовое уведомление!
   - Нажмите **«Сохранить настройки»**.

Готово! Теперь при любом новом заказе на сайте вам в Telegram будет приходить аккуратное форматированное сообщение со всеми данными покупателя и списком товаров.

## 📁 Структура проекта

```
product-catalog/
├── server.js            # Сервер Node.js (HTTP + node:sqlite + Telegram API)
├── database.db          # База данных SQLite (создается автоматически)
├── start.bat            # Скрипт быстрого запуска для Windows

├── public/              # Статические файлы фронтенда
│   ├── index.html       # Витрина магазина с Age-Gate и корзиной
│   ├── style.css        # Стили витрины магазина
│   ├── app.js           # Логика каталога, Age-Gate и оформления заказа
│   ├── admin.html       # Панель управления магазином
│   ├── admin.css        # Стили панели управления
│   └── admin.js         # Логика админки (CRUD, заказы, тест Telegram)
└── uploads/             # Папка для сохраненных изображений товаров
```
