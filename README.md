# 💨 FIZZY VAPE STORE — Онлайн-каталог с базой данных, вкусами, админ-панелью и Telegram-ботом

Полнофункциональный современный интернет-магазин одноразовых электронных сигарет (FIZZY VAPE), написанный на **Node.js** со встроенной базой данных SQLite (`node:sqlite`). Работает полностью без сторонних зависимостей (`node_modules` не требуются).

---

## 🌟 Возможности и функции

1. **Age-Gate (Проверка 18+)**:
   - Стильное всплывающее окно при входе: *"Вам есть 18 лет?"*
   - Допуск к витрине только при подтверждении возраста («Да»). Выбор сохраняется в браузере.
   - При выборе «Нет» доступ блокируется. Есть кнопка сброса для тестирования внизу страницы.

2. **Каталог товаров FIZZY с реальными фото и ценами в злотых (zł)**:
   - В каталог добавлены все 5 моделей со снимков накладной и прайс-листа:
     - **Fizzy Smart 150K (15 in 1)** — **115 zł**
     - **Fizzy Prime Max 80K** — **80 zł**
     - **Fizzy Max III 120K (6 in 1)** — **100 zł**
     - **Fizzy Twins 50K (Dual Tank)** — **70 zł**
     - **Fizzy X-Space 100K** — **95 zł**
   - Все фотографии аккуратно вырезаны, улучшены и сохранены в `/uploads/`.
   - Живой поиск и фильтрация по категориям (`Fizzy 150K`, `Fizzy 120K`, `Fizzy 100K`, `Fizzy 80K`, `Fizzy 50K`, `Все`).

3. **Выбор вкусов (Flavors)**:
   - Для каждого устройства загружен точный список вкусов из накладной.
   - На карточках отображаются превью-бейджы доступных вкусов.
   - При нажатии на товар или кнопку открывается модальное окно с выбором конкретного вкуса.
   - Корзина учитывает разные вкусы одной модели как отдельные позиции.
   - Выбранный вкус отображается в корзине и отправляется в Telegram!

4. **Корзина и оформление заказа**:
   - Выезжающая шторка корзины со счетчиком и управлением количеством (+ / − / 🗑️).
   - Форма заказа с именем, телефоном/Telegram-ником и комментарием с адресом доставки.
   - Поддержка Telegram WebApp (автозаполнение имени и никнейма покупателя при открытии внутри Telegram).

5. **Мгновенные уведомления в Telegram-бот**:
   - Оповещение с номером заказа, контактами клиента, выбранными товарами, **вкусами** каждого устройства и итоговой суммой в `zł`.
   - Ответ на `/start` прямо в боте с кнопкой «🛍 Открыть каталог товаров».

6. **Админ-панель (`/admin`)**:
   - Вход по паролю (по умолчанию: `admin123`).
   - Дашборд со статистикой: общая выручка, выручка за сегодня, выручка за месяц, количество заказов.
   - **Управление товарами**: добавление, редактирование, загрузка фото (Drag & Drop), настройка списка вкусов, удаление, скрытие/активация.
   - **История заказов по периодам**: фильтрация за *«Все время»*, *«Сегодня»*, *«Вчера»*, *«За 7 дней»*, *«Этот месяц»*.
   - **Кнопка «Очистить все заказы»**: позволяет обнулить общий баланс проданных товаров и очистить историю.
   - **Настройки Telegram**: сохранение токена и Chat ID, кнопка тестовой отправки сообщения.

## 🚀 Как запустить локально

### Быстрый запуск на Windows:
Дважды кликните по файлу **`start.bat`** в папке проекта.

### Через терминал:
```bash
node server.js
```
- 🛒 **Витрина магазина:** [http://localhost:3000](http://localhost:3000)
- ⚙️ **Админ-панель:** [http://localhost:3000/admin](http://localhost:3000/admin)
- 🔑 **Пароль админа по умолчанию:** `admin123`

## 🌐 Как обновить сайт на хостинге

Если у вас уже залит сайт на хостинг (Render, VPS, Timeweb, Beget и т.д.):
1. **Перезалейте обновленные файлы:**
   - `server.js`
   - `database.db` *(содержит уже настроенные 5 моделей с ценами в zł и вкусами)*
   - Папку `public/` (`index.html`, `style.css`, `app.js`, `admin.html`, `admin.js`, `admin.css`)
   - Папку `uploads/` *(содержит вырезанные фото устройств)*
2. **Перезапустите приложение на хостинге** (Restart service / `pm2 restart`).
3. В админ-панели (`/admin`) во вкладке «Telegram & Настройки» при необходимости укажите ваш `Bot Token` и `Chat ID`.
